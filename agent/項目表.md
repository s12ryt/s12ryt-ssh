# 專案文件與依賴

## 入口與介面

- `main.go`：Windows GUI 應用程式入口、vault 啟動流程與 Gio 視窗。
- `internal/gui/`：Gio 本機設定/登入、遠端登入校驗與本機/遠端資源操作畫面；只呼叫 backend/service。
- `internal/gui/ui_upgrade.go`：UI 疊代純邏輯（ANSI 過濾、terminal/output 上限、submit 消費、確認框狀態機、DB type 正規化、響應式堆疊、secret 遮罩、密碼顯示切換、busy/danger 配色、必填驗證、try* 動作方法）；與 window.go/remote_window.go 接線。

## 核心 backend

- `internal/config/`：非敏感 vault metadata 與 profile 型別；不再負責明文 secret persistence。
- `internal/vault/`：UUID、KDF、AES-GCM、復原金鑰與 vault 序列化。
- `internal/securestore/`：Windows bootstrap secret 安全儲存 adapter。
- `internal/storage/`：S3/R2 物件儲存與記憶體測試 backend；vault R2 adapter 依賴此介面。
- `internal/database/`：MySQL/PostgreSQL client 與 SQL vault adapter；避免循環依賴。
- `internal/ssh/`：SSH host key 驗證、timeout、Exec 與 PTY session。
- `internal/remote/`：Node API client、短期 access token、DPAPI refresh token、非敏感登入偏好及 S3/SQL proxy session。

## Node 身分驗證服務

- `server/src/domain/`：account、connection、operation、session 與 audit 型別；不依賴 Fastify/grammY/driver。
- `server/src/security/`：scrypt、AES-256-GCM、opaque token 與 token hash。
- `server/src/db/`、`server/src/repository/`：Node SQLite migration 與 prepared-statement repository。
- `server/src/services/`：帳號、connection、grant、session 與 authentication application service。
- `server/src/proxy/`、`server/src/adapters/`：授權代理邊界與 AWS S3/mysql2/pg adapters。
- `server/src/http/`：Fastify `/api/v1` API、rate limit、HTTPS/trusted proxy 邊界。
- `server/src/bot/`：Telegram 私聊管理 controller 與 grammY adapter。
- `server/src/runtime.ts`、`server/src/index.ts`：production dependency composition、audit retention、long polling 與 graceful shutdown。

## 測試與文件

- 各 package 的 `*_test.go`：先 RED、後 GREEN、再 REFACTOR；優先測可觀察契約。
- `.github/workflows/ci.yml`：push/PR 的 Node 22 與 Windows Go CI、版本矩陣、測試、靜態檢查、build、安全掃描。
- `.github/workflows/release.yml`：語意化版本 tag/手動觸發的 Windows amd64/arm64 發行建置與 checksums。
- `README.md`：GUI 建置、首次設定、vault 與功能說明。
- `server/README.md`：Node 環境、Telegram 管理、REST API、HTTPS、安全模型與遠端 GUI 部署說明。
- `agent/question.md`：唯一需求與驗收依據。
- `agent/deep_todos.md`：歷史、基線與當前進度。
- `agent/memory.md`：本次檔案操作與驗證紀錄。

## 主要依賴方向

`main.go -> internal/gui -> internal/app + internal/remote + internal/securestore`

`internal/gui local workspace -> internal/ssh/storage/database`

`internal/gui remote workspace -> internal/remote -> Node /api/v1`

`server runtime -> domain/services -> repository + proxy interfaces -> Fastify/grammY/AWS/mysql2/pg adapters`

`internal/vault -> storage.Storage 或 vault backend interface`

`internal/database -> config`；`internal/storage -> config`；`internal/ssh -> config`

backend package 不依賴 Gio，確保可單元測試與重用。
