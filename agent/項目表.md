# 專案結構與依賴

## 入口與介面

- `main.go`：Windows GUI 應用入口；Gio 標準退出模式（main 只調 app.Main()，背景 goroutine 以 os.Exit 結束進程）、DPAPI securestore、遠端服務偏好與 Gio 視窗組裝。
- `internal/gui/`：Gio 遠端登入與遠端工作區介面（主機首頁、六模組導覽、SSH/SFTP/隧道/快捷指令/金鑰/指紋/工作階段頁）；登入支援可選的 DPAPI 記住密碼與啟動自動登入失敗清除。版面沿用 4dp 節奏、深色 teal、欄位標籤與 surface 層級。SSH 工作區有常駐主機清單、窄版水平主機列、終端分頁及 modal 表單。
- `internal/gui/ui_upgrade.go`：GUI 共用邏輯（ANSI 過濾、terminal/output 上限、submit 偵測、FIFO 確認對話佇列、編輯列、secret 顯隱、busy/danger 色系、等寬字型、tryRemoteSignIn 動作）。
- `internal/gui/remote_ssh.go`：遠端 SSH 主機與多終端分頁流程（憑證下發、TOFU fingerprint 確認、每分頁 PTY/input/output/VT/SFTP、剪貼簿、SFTP drop target、重試、拖曳排序、主機停用級聯與資源釋放）。
- `internal/gui/remote_tunnel.go`、`ssh_tunnel_state.go`：隧道CRUD與local/remote/dynamic SOCKS runtime；依HostID+Version共用transport，啟停與流量以五秒節流best-effort同步服務端，停止前擷取最終計數。
- `internal/gui/terminal_appearance.go`、`remote_appearance.go`、`local_terminal_windows.go`：終端字型／字級／palette正規化與渲染、帳號預設與主機覆寫的遠端同步；Windows本機終端使用ConPTY，其他平台使用pipe fallback。
- `internal/gui/ssh_workspace_state.go`：SSH tab/SFTP session 狀態、獨立資源、併發保護、分頁操作、按主機關閉資源、表單 dirty 判斷與響應式版面門檻。
- `internal/gui/remote_history.go`、`ssh_session_history_state.go`、`ssh_session_history_page.go`：工作階段歷史的 optional 遠端同步、attempt token、stale 結果隔離、唯讀 metadata 頁與生命週期更新。
- `internal/gui/ssh_workspace_import.go`、`ssh_workspace_import_file.go`、`workspace_file_dialog.go`、`workspace_import_export.go`、`workspace_import_export_form.go`：opaque 工作區匯入／匯出狀態、16 MiB 檔案邊界、原生檔案選擇器、加密密碼表單、預覽與衝突決策。
- `internal/gui/workspace_shell.go`：六模組工作區殼層；Hosts 頁提供 workspace import/export，其他已完成模組各自接入真實頁面，未完成模組顯示誠實狀態。
- `internal/gui/sftp_drop.go`、`sftp_transfer.go`、`sftp_transfer_panel.go`：SFTP 拖放 URI／Windows 路徑解析、大小限制、傳輸速率／ETA／可選 SHA-256 驗證、續傳 worker 與全域底部傳輸面板。

## 核心套件

- `internal/config/`：SSHProfile 型別（含 KeyData 私鑰內容）與 JSON 存取。
- `internal/securestore/`：Windows DPAPI refresh token 與可選登入密碼的本機保存 adapter。
- `internal/ssh/`：SSH host key 驗證、timeout、Exec、PTY、SFTP與local/remote/dynamic SOCKS forwarding；支援 KeyPath 與 KeyData 私鑰。
- `internal/remote/`：Node API client、短期 access token、DPAPI refresh token 與可選記住登入密碼、SSH hosts/SFTP/隧道/快捷指令/金鑰/指紋/工作階段歷史與 workspace import/export API，以及 ResourcesOverview（含 sshEnabled）。S3/SQL proxy 已於 2026-08-29 移除。
- `internal/i18n/`：英文/繁體中介面字典（遠端登入、SSH 工作區、終端、SFTP、隧道、快捷指令、金鑰、指紋與歷史頁用字）。

## 主要依賴方向

`main.go -> internal/gui + internal/remote + internal/securestore`

`internal/gui remote workspace -> internal/remote（SSH hosts、ResourcesOverview）-> Node /api/v1（服務端在 s12ryt-ssh-auth-server 倉庫）`

`internal/gui SSH tab -> internal/ssh（客戶端直連）+ internal/remote（憑證下發）`

`internal/ssh -> config`；`internal/remote -> securestore`

`workspace import/export -> internal/remote -> s12ryt-ssh-auth-server`；匯入匯出 payload 以 opaque package 傳遞，秘密不進 GUI metadata store。

本機 Vault（internal/vault、internal/storage、internal/database、internal/app）已於 2026-08-29 移除；應用唯一入口為遠端登入。
