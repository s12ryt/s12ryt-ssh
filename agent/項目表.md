# 專案結構與依賴

## 入口與介面

- `main.go`：Windows GUI 應用入口；Gio 標準退出模式（main 只調 app.Main()，背景 goroutine 以 os.Exit 結束進程）、DPAPI securestore、遠端服務偏好與 Gio 視窗組裝。
- `internal/gui/`：Gio 遠端登入與遠端工作區介面（SSH 主機管理與 PTY 終端；帳號未啟用 SSH 時顯示提示）；版面沿用 4dp 節奏、深色 teal、欄位標籤與 surface 層級。2026-08-30 SSH 工作區改為常駐主機清單、窄版水平主機列、終端分頁及主機表單 modal。
- `internal/gui/ui_upgrade.go`：GUI 共用邏輯（ANSI 過濾、terminal/output 上限、submit 偵測、FIFO 確認對話佇列、三欄編輯列、secret 顯隱、busy/danger 色系、等寬字型、tryRemoteSignIn 動作）。
- `internal/gui/remote_ssh.go`：遠端 SSH 主機清單與 modal 表單、多終端分頁連線流程（憑證下發、TOFU fingerprint 確認、每分頁 PTY/input/output、失敗重試與資源釋放）。
- `internal/gui/ssh_workspace_state.go`：SSH 終端分頁狀態、獨立 session 資源、併發保護、表單 dirty 判斷與響應式版面門檻。

## 核心套件

- `internal/config/`：SSHProfile 型別（含 KeyData 私鑰內容）與 JSON 存取。
- `internal/securestore/`：Windows DPAPI refresh token 本機保存 adapter。
- `internal/ssh/`：SSH host key 驗證、timeout、Exec 與 PTY session；支援 KeyPath 與 KeyData 私鑰。
- `internal/remote/`：Node API client、短期 access token、DPAPI refresh token、SSH hosts API client（CRUD/憑證下發/fingerprint）與 ResourcesOverview（含 sshEnabled）。S3/SQL proxy 已於 2026-08-29 移除。
- `internal/i18n/`：英文/繁體中介面字典（遠端登入、SSH 工作區、終端狀態與主機表單用字）。

## 遠端驗證服務（獨立倉庫）

- Node 22 驗證服務已於 2026-08-29 以 `git subtree split -P server` 拆至 https://github.com/s12ryt/s12ryt-ssh-auth-server（13 個歷史提交保留）；SSH hosts API、帳號 ssh_enabled 開關與 Bot 指令同日加入（main=68d732d）。桌面客戶端已於 2026-08-29 移除 S3/SQL 代理使用，服務端 S3/SQL 功能不再被本倉庫使用。
- Go GUI 以「遠端登入」為唯一入口；服務端架構與 API 契約見該倉庫 README。

## 測試與建置

- 各 package 的 `*_test.go`：先 RED、後 GREEN、再 REFACTOR；行為驅動斷言。
- `.github/workflows/ci.yml`：push/PR 跑雙版本 Go 測試、靜態分析、弱點檢查、build、密掃描（internal/i18n 測試因本機防毒誤判僅在 CI 執行）。
- `.github/workflows/release.yml`：人工 tag/手動觸發的 Windows amd64/arm64 發布構建與 checksums。
- `README.md`：遠端架構、SSH 主機管理、安全模型說明。
- 驗證服務：Node 測試、Telegram 管理、REST API、稽核，見 s12ryt-ssh-auth-server 倉庫 README。
- `agent/question.md`：唯一需求與驗收依據。
- `agent/deep_todos.md`：歷史任務與工作進度。
- `agent/memory.md`：檔案操作與測試記錄。

## 主要依賴方向

`main.go -> internal/gui + internal/remote + internal/securestore`

`internal/gui remote workspace -> internal/remote（SSH hosts、ResourcesOverview）-> Node /api/v1（服務端在 s12ryt-ssh-auth-server 倉庫）`

`internal/gui SSH tab -> internal/ssh（客戶端直連）+ internal/remote（憑證下發）`

`internal/ssh -> config`；`internal/remote -> securestore`

本機 Vault（internal/vault、internal/storage、internal/database、internal/app）已於 2026-08-29 移除；應用唯一入口為遠端登入。
